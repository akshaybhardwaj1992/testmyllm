# testmyllm-mcp

An MCP server that lets AI assistants (Claude Code, Claude Desktop, any MCP client) use TestMyLLM.
It uses the same project API tokens as the CLI.

| Tool | What it does |
|---|---|
| `list_projects` | Lists the projects the token can see, with each one's latest run. |
| `score_answers` | Scores 1–5 answers to a question with Ragas and DeepEval. Optional inputs: a reference answer, context, or criteria. |
| `run_evaluation` | Starts a suite or dataset run, or repeats an earlier run. Answers can be recorded ones or generated by a model. |
| `get_run` | Returns status, per-metric summary and failed cases with judge reasons. For security scans it returns ASR per OWASP category and the findings. |
| `compare_runs` | Compares a candidate run with a baseline (regression report), with an optional quality-gate preview. |

## Cost guard

Tools that start paid work refuse when the server's estimate exceeds `max_estimated_usd`:
- `score_answers`: limit 0.25 by default
- `run_evaluation`: limit 1.00 by default

The same value is set as the run's budget cap.

## Install and connect

```bash
pip install ./mcp_server          # Python 3.10+
# Claude Code
claude mcp add testmyllm --env TESTMYLLM_URL=http://localhost:8080 --env TESTMYLLM_TOKEN=tml_... -- testmyllm-mcp
```

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "testmyllm": {
      "command": "testmyllm-mcp",
      "env": { "TESTMYLLM_URL": "http://localhost:8080", "TESTMYLLM_TOKEN": "tml_..." }
    }
  }
}
```

Use an **editor** token to start runs, or a **viewer** token for read-only access (`list_projects`,
`get_run`, `compare_runs`). Create tokens under Settings → Integrations → API tokens.
